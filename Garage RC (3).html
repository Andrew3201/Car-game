Channels

Channels with the same unit share a strip and a scale. Hover the plot to read values at that moment.

Bindings

Each row connects one control to one target. Click the control name, then move a stick or press a button or key to change it. Rows with the same target add together. The three direct targets drive the car when no program is running; a running program reads them, and any variable you name, as input.name (easy mode) or radio.name (realistic mode).
